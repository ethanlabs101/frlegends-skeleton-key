## What is FR Legends Skeleton Key?

FR Legends Skeleton Key is a powerful toolkit for managing
FR Legends accounts, save data, assets, and customization
through a simple command-line interface.

It provides tools for managing your Vault, working with
player data, installing community assets, managing liveries,
and more — all from one application.

Whether you're looking to manage your own saves, install
custom content, or explore what Skeleton Key can do,
everything is designed to work together through the Vault.

---

### What can it do?

- 🔐 Manage multiple FR Legends accounts
- 💾 Securely store account data in your local Vault
- 🚗 Manage and inject vehicle assets
- 🎨 Work with custom liveries
- 📦 Browse and download assets from the Online Asset Manager
- 🛠️ Modify supported player data
- 💰 Manage supported game data
- ♻️ Remotely clone and create accounts
- 🔄 Safely update Skeleton Key without overwriting your Vault
- 💻 Run on supported Linux and Termux/Debian environments

***and much much more!***
