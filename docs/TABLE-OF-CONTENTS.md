# 📌 Documentation Philosophy

Skeleton Key's documentation is divided into three levels:

### User Level

**What can Skeleton Key do and how do I use it?**

Installation, onboarding, navigation, sandbox tools, and asset management.

### Reference Level

**What features and resources are available?**

Feature lists, troubleshooting, changelog, directory structure, and project information.

### Technical Level

**How does Skeleton Key actually work?**

Architecture, serialization, asset construction, save processing, reverse-engineered structures, and development internals.

This separation keeps the normal user experience approachable while still giving technically curious users a deeper path into the project.
